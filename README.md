# 十里人生｜十里方圓角色模擬遊戲（期末版）

手機優先的 8-bit 像素風網頁遊戲。依學姊簡報第 8–10 頁設計：**同一件事、四個角色、四輪決策**，各方的選擇會一起改變「供貨、交期、人力、信任」，最後產生「影響報告」。

> ⚠ 所有角色、事件與數值皆為**虛構模擬**，文字與合作社連結尚待合作社確認。

## 執行

需要 Node.js 18 以上。

```bash
npm install
npm run dev      # 開發
npm run build    # 打包到 dist/
npm run check    # 檢查資料與結局可達性
```

## 玩法

1. 抽角色：小農、合作社經營者、消費者、合作社社員（四選一）。
2. 共同事件：共同購買需求增加（50 份訂單 vs 30 份供貨）。
3. 四輪依序：小農 → 經營者 → 消費者 → 社員。輪到自己時從 3 個選項選 1；其他角色由固定規則（`computerPick`）決定。
4. 共同狀態四項（0–10，開局 供貨4／交期5／人力5／信任5）：每個選項會改變其中幾項。
5. 影響報告：結局、四項狀態、各角色處境、每輪發生了什麼、圖鑑進度（localStorage）、真實合作社服務。

結局（由上而下判定）：關係出現裂縫、貨到了人累了、願意等的人、一起把事做成、勉強撐過去。

## 程式位置

- `src/data/shared.ts`：事件、四輪選項與效果、電腦規則、結局條件、角色處境文字
- `src/engine/shared.ts`：狀態計算與結局判定；`src/engine/collection.ts`：圖鑑紀錄
- `src/screens/`：Start → RoleDraw → Story → SharedEvent → Round ×4 → Report

## 八角色對話樹

8 角色兩兩對話（28 組）不放在遊戲內，改以 Excel「8角色對話樹」與關係圖頁面呈現，供合作社校正。舊版 pair 模式檔案（`pairs.ts`、`peopleTexts.ts` 等）保留但未使用。

## 待辦

- 合作社確認文字、數值與連結（`COOP_URL`）
- 驗證指標：完成率、理解度、重玩率、回饋
- 「貨到了人累了」結局目前單一選擇路徑較難到達，可再調整
